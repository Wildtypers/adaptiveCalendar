Technology & Dependency Roadmap
Phase 1 — Project Initialization (2.4)

Install these immediately.

Dependency	Purpose	Why Needed
flutter_riverpod	State management	Share application state across screens.
go_router	Navigation	Manage application routing and future deep linking.
drift	Local database ORM	Persistent local SQL database.
sqlite3_flutter_libs	SQLite runtime	Required for Drift.
path_provider	Local storage paths	Locate the database file.
path	File path utilities	Construct platform-independent paths.
intl	Date and time formatting	Calendar, timers, and analytics.
uuid	Unique identifiers	Future-proof task IDs for cloud synchronization.
logging	Structured logging	Debugging and monitoring during development.
